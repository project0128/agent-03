## 设计目标

构建一个**本地运行、可自我进化、安全可控**的陪伴型 AI Agent 底座：

1. **长期陪伴**：通过持久化记忆系统，记住与用户的交互历史
2. **自我进化**：在安全约束下，AI 可以优化自己的提示词和策略
3. **隐私优先**：所有数据本地存储，不依赖云端服务
4. **安全可控**：通过宪法层、沙箱层、验证层三重防护

---

## 架构概览

| 层级 | 组件 | 职责 |
|------|------|------|
| **宪法层** | `constitution.md` | 定义不可违反的安全边界 |
| **沙箱层** | Docker 容器 | 隔离执行环境，限制资源访问 |
| **验证层** | 测试集 + 评分器 | 验证自我修改的安全性 |
| **对话层** | 对话引擎 | 处理用户交互，生成回复 |
| **记忆层** | 记忆系统 | 存储和检索长期记忆 |
| **进化层** | 自我优化器 | 在约束下优化提示词和策略 |

---

## 关键机制

### 1. 安全约束框架

- **宪法锁定**：核心安全规则通过 SHA-256 哈希锁定，AI 无法修改
- **沙箱隔离**：AI 代码在 Docker 容器中运行，无法访问宿主系统
- **自动回滚**：自我修改必须通过验证，失败自动回滚

### 2. 记忆系统

- **短期记忆**：当前对话上下文
- **长期记忆**：用户偏好、重要事件、情感模式
- **记忆压缩**：定期压缩旧记忆，保留关键信息

### 3. 自我进化

- **提示词优化**：AI 可以提议修改自己的系统提示词
- **策略调整**：根据对话质量自动调整回复策略
- **验证门禁**：所有修改必须通过隐藏测试集验证

---

## 设计取舍

| 选择 | 原因 |
|------|------|
| 本地优先 | 保护用户隐私，避免数据泄露 |
| 沙箱隔离 | 防止 AI 越权操作，确保安全 |
| 宪法锁定 | 防止 AI 绕过安全约束 |
| 自动回滚 | 防止自我进化导致系统崩溃 |
| 隐藏测试集 | 防止 AI 针对测试集过拟合 |
