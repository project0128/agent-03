# 03

> 本地陪伴型 Agent 底座 · 8B 常驻推理 · 人格可训练替换 · 模块化可扩展

03 是一个面向个人本地部署的陪伴型 Agent 底座。它由小模型常驻响应以维持低延迟的陪伴感，复杂任务通过路由层按需调度更大模型（规划中）。其默认人格可被清空，用户能导入自己的对话、笔记与偏好语料，训练出想要的交流形态。整个项目的模型、记忆和日志均保留在本地，不依赖任何云端服务。

03 不追求成为功能最全的开源 Agent，而是提供一个稳定、可训练、可长期运行的轻量底座——Router、Memory、Runtime 与 Training 层均通过接口隔离，可独立替换，主循环保持不变。

> **⚠️ 当前状态：早期开发阶段。** 已实现骨架与主循环；大小模型切换、向量记忆、微调管线为规划目标，尚未实现。模块逐步补齐中。

---

## 设计目标

| 目标 | 说明 |
|------|------|
| 本地优先 | 模型、记忆、日志全部落本地，无云端依赖 |
| 人格可替换 | 默认人格可清空，支持用户自有语料微调（训练管线规划中） |
| 模块化设计 | Router / Memory / Runtime / Training 通过接口隔离，可独立替换 |
| 小模型常驻 | 8B 日常响应保持陪伴感，复杂任务按需升级 14B/32B |

## 关键机制

### 路由层（规划中）

按「规则 → 分类器 → 置信度兜底」三层设计，待实测验证。

当前实现「伪路由」：接口和日志结构已就绪（输出 `model_tag + reason + confidence`），后续换硬件时直接接入实现，无需重构。

### 记忆层（规划中）

- 短期记忆：当前对话上下文
- 长期记忆：用户偏好、重要事件、情感模式
- 记忆压缩：定期压缩旧记忆，保留关键信息

### 人格训练（规划中）

- 默认人格可清空
- 支持导入对话、笔记与偏好语料
- 微调管线待实现

## 设计取舍

| 选择 | 原因 |
|------|------|
| 本地优先 | 保护用户隐私，避免数据泄露 |
| 小模型常驻 | 降低延迟，保持陪伴感 |
| 接口隔离 | 各层可独立替换，主循环不变 |
| 伪路由先行 | 先跑通接口，后续直接接入实现 |
| 隐藏测试集 | 防止 AI 针对测试集过拟合 |

## 硬件建议

> 本项目开发与测试环境：**单卡 8G 显存**。更大模型的调度为设计目标，欢迎有资源的同学协助实测。

| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 4 核 | 8 核+ |
| 内存 | 8 GB | 16 GB+ |
| 存储 | 20 GB SSD | 50 GB+ SSD |
| GPU | 无（CPU 推理） | NVIDIA 8GB+ VRAM |
| 网络 | 无（本地运行） | 可选（模型下载） |

**推理性能参考**（Qwen3-8B, Q4_K_M 量化）：
- CPU (i7-12700): ~5 tokens/s
- GPU (RTX 3060): ~30 tokens/s
