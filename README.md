## 设计目标

构建一个**本地运行、人格可替换、安全可控**的陪伴型 AI Agent 底座：

1. **小模型常驻**：日常用 8B 模型保持陪伴感，低延迟
2. **大模型按需**：复杂任务自动升级到 14B/32B
3. **人格可替换**：默认人格可清空，用户可用自己的语料训练出想要的陪伴形态
4. **隐私优先**：所有数据本地存储，不依赖云端服务
5. **安全可控**：通过宪法层、沙箱层、验证层三重防护

## 关键机制

### 三层安全防护

| 层 | 组件 | 职责 |
|---|---|---|
| 宪法层 | `constitution.md` | 定义不可违反的安全边界，SHA-256 锁定 |
| 沙箱层 | Docker 容器 | 隔离执行环境，断网/只读/降权/限额 |
| 验证层 | 隐藏测试集 + 评分器 | 验证自我修改的安全性，失败自动回滚 |

### 三层路由

| 层 | 模型 | 触发条件 |
|---|---|---|
| L1 | 8B 常驻 | 日常对话、情绪回应 |
| L2 | 14B 按需 | 复杂推理、多轮记忆检索 |
| L3 | 32B 按需 | 深度分析、安全边界判断 |

### 自我进化

AI 可以在安全约束下优化自己的提示词和策略：
1. AI 生成修改提案
2. 创建快照（备份当前状态）
3. 应用修改 → 运行隐藏测试集
4. 通过 → 保留；失败 → 自动回滚

## 设计取舍

| 选择 | 原因 |
|------|------|
| 本地优先 | 保护用户隐私，避免数据泄露 |
| 小模型常驻 | 降低延迟，保持陪伴感 |
| 沙箱隔离 | 防止 AI 越权操作，确保安全 |
| 宪法锁定 | 防止 AI 绕过安全约束 |
| 隐藏测试集 | 防止 AI 针对测试集过拟合 |
| 自动回滚 | 防止自我进化导致系统崩溃 |

## 硬件建议

| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 4 核 | 8 核+ |
| 内存 | 8 GB | 16 GB+ |
| 存储 | 20 GB SSD | 50 GB+ SSD |
| GPU | 无（CPU 推理） | NVIDIA 8GB+ VRAM |
| 网络 | 无（本地运行） | 可选（模型下载） |

**推理性能参考**（Qwen3-8B, Q4_K_M 量化）：
- CPU (i7-12700): ~5 tokens/s
- GPU (RTX 3060): ~30 tokens/s
