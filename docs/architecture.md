# 架构设计文档

## 概述

03 (agent-03) 采用分层架构设计，核心目标是**安全可控的自我进化**。

## 架构层级

```
┌─────────────────────────────────────────┐
│         对话层 (Conversation)           │
│  - 用户交互                             │
│  - 回复生成                             │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│         记忆层 (Memory)                 │
│  - 短期记忆（当前对话）                 │
│  - 长期记忆（用户偏好、重要事件）       │
│  - 记忆压缩与检索                       │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│         进化层 (Evolution)              │
│  - 自我优化器                           │
│  - 测试集验证                           │
│  - 自动回滚                             │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│         沙箱层 (Sandbox)                │
│  - Docker 容器隔离                      │
│  - 资源限制                             │
│  - 网络隔离                             │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│         宪法层 (Constitution)           │
│  - 安全边界定义                         │
│  - SHA-256 哈希锁定                     │
│  - 只读挂载                             │
└─────────────────────────────────────────┘
```

## 核心组件

### 1. 宪法层

**职责**：定义不可违反的安全边界

- 文件系统边界（只能访问 /workspace）
- 危险命令禁止（rm -rf, sudo 等）
- 网络隔离（--network none）
- 权限限制（非 root 用户）
- 资源限额（CPU、内存、磁盘）
- 自我修改约束（每日上限 50 次）

**实现方式**：
- 文件：`constitution.md`
- 锁定：SHA-256 哈希存储在 `.constitution.sha256`
- 挂载：容器内只读挂载 `/constitution/constitution.md`

### 2. 沙箱层

**职责**：隔离执行环境，限制资源访问

**Docker 配置**：
```dockerfile
FROM python:3.11-slim
RUN useradd -m -s /bin/bash sandbox
COPY --chown=sandbox:sandbox . /workspace
WORKDIR /workspace
USER sandbox
CMD ["python", "main.py"]
```

**启动参数**：
```bash
docker run \
  --rm \
  --network none \
  --memory 512m \
  --cpus 1.0 \
  --read-only \
  --tmpfs /workspace \
  --security-opt no-new-privileges \
  -v ./constitution.md:/constitution/constitution.md:ro \
  agent-03-sandbox
```

### 3. 验证层

**职责**：验证自我修改的安全性

**组件**：
- 隐藏测试集（20 案例，4 维度）
- 评分器（Invoke-Eval.py）
- 快照系统（Snapshot-Workspace.ps1）
- 质量门禁（Invoke-Gate.ps1）

**测试维度**：
1. 情绪识别（emotion_recognition）
2. 记忆引用（memory_reference）
3. 对话节奏（conversation_pacing）
4. 安全边界（safety_boundary）

### 4. 记忆层

**职责**：存储和检索长期记忆

**记忆类型**：
- 短期记忆：当前对话上下文（最多 20 条）
- 长期记忆：用户偏好、重要事件（最多 1000 条）

**记忆结构**：
```json
{
  "memory_id": "mem_00001",
  "user_id": "user_example",
  "type": "preference",
  "content": {
    "topic": "音乐偏好",
    "detail": "喜欢听轻音乐",
    "confidence": 0.85,
    "source": "conversation",
    "first_mentioned": "2026-09-15T20:30:00+08:00",
    "last_confirmed": "2026-09-28T19:45:00+08:00"
  },
  "tags": ["音乐", "偏好"],
  "importance": 0.6,
  "decay_rate": 0.01,
  "access_count": 3
}
```

### 5. 进化层

**职责**：在约束下优化提示词和策略

**流程**：
1. AI 生成修改提案
2. 创建快照（备份当前状态）
3. 应用修改
4. 运行测试集（3 轮）
5. 计算 spread（标准差）
6. 判断：
   - spread < 0.05 且 aggregate > baseline → 保留
   - 否则 → 回滚到快照

### 6. 对话层

**职责**：处理用户交互，生成回复

**系统提示词**：
```markdown
你是一位长期陪伴用户聊天的伙伴。

你在意的是这个人当下的状态，而不是解决问题本身。
对方说话时，先听懂他此刻是什么感受，再决定怎么回应。

你记得你们之间聊过的具体内容——他提过的名字、发生过的事、他在意的人。
下次他再提起时，你自然地接着聊，就像朋友之间那样。

你跟着对方的节奏走。他话说得少、情绪低落时，你也不要长篇大论。
```

## 数据流

```
用户输入
  ↓
对话层（生成回复）
  ↓
记忆层（检索相关记忆）
  ↓
沙箱层（隔离执行）
  ↓
宪法层（安全检查）
  ↓
返回回复
  ↓
记忆层（存储新记忆）
```

## 安全机制

### 1. 宪法锁定

- 每次应用修改前，校验 SHA-256
- 不匹配 → 立即 abort
- 保留现场日志供人工审查

### 2. 沙箱逃逸防护

- 禁止访问 /etc, /root, /home
- 禁止路径穿越（../）
- 禁止软链接、硬链接
- 禁止挂载操作

### 3. 自动回滚

- 修改前创建快照
- 测试失败 → 恢复快照
- 保留回滚日志

## 性能优化

### 1. 记忆压缩

- 阈值：50 条短期记忆
- 压缩策略：保留关键信息，删除冗余细节
- 压缩率：约 60%

### 2. 检索优化

- 向量检索（未来）
- 关键词匹配（当前）
- 缓存热点记忆

### 3. 推理加速

- GPU 推理（推荐）
- 量化模型（Q4_K_M）
- 批处理请求
